# @suno/desktop

Powłoka Tauri 2 dla Suno Studio. Frontend to `apps/web` budowany w trybie `tauri`
(`beforeDevCommand` / `beforeBuildCommand` w `src-tauri/tauri.conf.json`), backend to Convex.
Rust dostarcza wyłącznie pluginy natywne (fs, dialog, http, store, updater, process).

Polecenia, wydania i podpisywanie: zobacz [README w korzeniu repo](../../README.md#desktop).
